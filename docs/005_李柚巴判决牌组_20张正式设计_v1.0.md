> 本文冻结李柚巴首发牌组：**10张天堂正位 + 10张地狱逆位**。
>
> 设计核心：**赌局感 + 反差坏笑 + Double or Nothing + Jackpot + 实际 Discord 执行**。
>
> 安全边界：本牌组所有“赌局 / 赌债 / 梭哈 / Jackpot”均为应用内娱乐机制，只涉及虚拟状态、昵称、临时身份组和抽卡流程，**禁止接入真钱、现金等价物、充值、兑换或现实财物输赢**。

---

## 1. 李柚巴牌组总规则

- 天堂 = 正位；地狱 = 逆位。
- 李柚巴牌组 UI 主色：黑 / 白 / 酒红 / 金 / 少量青绿色。
- 召唤动画：金币光点与纸牌飞散 → 三至五张塔罗像扑克牌一样洗牌 → 玩家亲手选牌 → 卡面翻转。
- 她是三位老板娘里“二次选择”最多的一位，但二次选择必须明确展示概率和后果，不做暗箱。
- `Double or Nothing` 只作用于当前应用判决，不允许影响现实财物。
- 昵称不得无限叠加；同一时间只允许一个主动昵称判决效果。
- 身份组均为 Bot 管理的临时装饰组，不改变频道权限。
- 天堂牌可移除或抵消部分既有刑罚。
- 地狱牌最高默认持续时间不超过 24h。
- 若 Bot 无法执行实体效果，则降级为 Activity 内称号 / 状态，并明确显示“服务器效果执行失败”。

建议权重：
- R：60%
- SR：30%
- SSR：10%

- 立即移除当前所有由本 Bot 添加的 R / SR 临时刑罚身份组。
- 添加身份组：`🎰 JACKPOT 幸运儿`
- 持续：24h

**附加状态**：
- 未来 24h 内第一次地狱 R / SR 判决只显示动画与判词，不执行实体刑罚。
- SSR 地狱不受保护。

## P-LYB-05｜R｜《再来一局》

**判词**：
> “就这么走啦？再陪我玩一局嘛。”

**Activity 交互**：
- 弹出：`[再赌一次] [我怂了]`
- 选择“我怂了”：
  - 添加身份组：`😼 李柚巴认证·怂了`
  - 持续：2h
- 选择“再赌一次”：进入 50/50 小赌局。
  - 赢：当前这张牌实体刑罚取消。
  - 输：改为执行 P-LYB-01《小输一把》+ `🎲 赌债未清` 身份组 3h。

**限制**：
- 只允许一次，不得再次递归触发“再来一局”。

---

## P-LYB-06｜SR｜《Double or Nothing》

**判词**：
> “翻倍，还是归零？你敢不敢自己按？”

**Activity 交互**：
- 玩家必须在 15 秒内选择：`[翻倍] [算了]`
- 选择“算了”：维持基础刑罚：
  - 身份组：`🎲 赌债未清`
  - 4h
- 选择“翻倍”：公开显示 50/50 概率。
  - 赢：本牌实体刑罚归零。
  - 输：昵称 `输给李柚巴两次的{原昵称}` + 身份组 `🎲 双倍赌债`
  - 持续：6h

**公平要求**：
- 服务端生成结果。
- 结果日志记录随机种子/判定值或等价可审计字段。
- 前端不得预先决定结果。

## P-LYB-10｜SSR｜《庄家通吃》

**判词**：

- 昵称：`被李柚巴通吃的{原昵称}`

- 可将持续时间从 12h 降为 8h，但身份组不取消。
- 每次判决仅可求饶一次。

# 4. 李柚巴专属召唤动画

## 4.1 普通召唤

1. 屏幕压暗，烛火映出酒红与金色反光。
2. 四张扑克牌从屏幕边缘飞入。
3. 牌面在中央洗牌 1.2s。
4. 其中三张变为塔罗牌背。
5. 李柚巴半身剪影短暂出现，手指从牌背上划过。
6. 玩家亲手选一张。
7. 卡牌翻转前，筹码弹起一次，颜色预告稀有度。

## 4.2 SR 演出

- 洗牌速度更快。
- 牌桌出现酒红色光圈。
- 李柚巴会额外丢出一张“假牌”，再收回。
- 翻牌时增加短促金色闪光。

## 4.3 SSR 演出

- 动画必须进入“赌场错觉”阶段：
  - 教堂地面像牌桌一样展开。
  - 彩窗变成抽象符号槽。
  - 钟声与筹码声结合。
  - 最终牌面出现前静音 0.5–0.8s。
- `JACKPOT` 与 `庄家通吃` 必须使用完全相反的明暗节奏。

# 5. 昵称刑罚规则

必须复用 `002` 的安全恢复协议：

1. 执行前记录：
   - user_id
   - guild_id
   - original_nickname
   - applied_nickname
   - effect_id
   - expires_at
2. 到期前再次读取当前昵称。
3. 只有当当前昵称仍等于 `applied_nickname` 时，才恢复 `original_nickname`。
4. 若玩家期间自己改了昵称，不得覆盖她的新昵称。
5. 多个判决不能无限前缀叠加。
6. Discord 昵称长度超限时，优先保留判决前缀，安全截断原昵称。

- `🎰 JACKPOT 幸运儿`

- 不赋予管理员、频道访问、禁言、踢人等权限。
- Bot 只回收自己添加的身份组。
- 到期任务失败必须重试并记录。

# 7. 表情包联动

李柚巴是三位老板娘里表情包使用频率最高的一位。

建议映射：
- 赢：得意 / 眨眼 / 比心
- 输：坏笑 / 看热闹 / 摊手
- Double or Nothing：挑衅 / 指向按钮
- 玩家选择“怂了”：笑到弯腰 / 调侃
- JACKPOT：惊讶后开心
- HOUSE WINS：坏笑 / 胜利手势

表情包发送必须是匿名 Activity 消息，不暴露修女操作者真实 Discord 身份。

---

# 8. QA 验收

静静施工时必须至少验证：

- 20 张牌全部可从 manifest 正常读取。
- 权重抽取不会出现 0 权重 / 重复 ID / 不存在资源。
- `Double or Nothing` 服务端结果与前端展示一致。
- 二次抽卡不会递归无限触发。
- Jackpot 可正确净化 R / SR 刑罚。
- SSR 地狱不被普通 Lucky Chip 抵消。
- 昵称恢复遵循“用户手动改名不覆盖”规则。
- 临时身份组到期可回收。
- Bot 权限不足时能安全降级。
- Android 小屏可完整显示“翻倍 / 算了 / 怂了”等按钮。
- 动画可设置“减少动态效果”，避免低端手机卡顿。

## 9. 冻结结论

李柚巴首发 20 张判决牌正式冻结。

三位修女老板娘首发牌组至此组成：

- 龙卷：暴力训诫 / 风暴庇护
- 山城恋：高位命令 / 服从认证
- 李柚巴：赌局随机 / 翻倍归零 / Jackpot

三套牌必须在视觉、交互、昵称语法、身份组与 SSR 演出上保持明显区分。
