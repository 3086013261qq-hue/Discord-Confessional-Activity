## 1. 判决总流程

固定流程：

1. 修女侧点击 `☁️ 天堂` 或 `🔥 地狱`。
2. 忏悔者界面立即锁定普通输入，进入全屏判决演出。
3. 天堂只进入正位牌池；地狱只进入逆位牌池。
4. 系统随机选中三位修女老板娘之一：龙卷 / 山城恋 / 李柚巴。
5. 进入对应老板娘专属召唤动画。
6. 五张背面朝上的塔罗牌展开，忏悔者必须亲手点一张。
7. 点击后先揭示稀有度，再翻牌显示角色卡面、牌名、判词、奖励或刑罚。
8. 若该牌包含 Discord 实体效果，则后端 Bot 立即执行。
9. 显示“审判已执行”结算页，并写入匿名审判记录。
10. 到期后自动恢复昵称 / 回收临时身份组；恢复失败必须重试并记录，不允许静默失败。

## 2. 抽卡动画总基调

参考高完成度二次元抽卡的“蓄力—飞行—稀有度预告—角色降临—翻牌”节奏，但不得复制其他游戏 UI、字体、星级图标或逐帧素材。

我们的视觉主题固定为：

**哥特教堂 × 塔罗 × 彩窗 × 烛火 × 天堂/地狱二极裁决。**

### 2.1 天堂正位演出

- 屏幕先压暗。
- 教堂钟声响起一次。
- 彩窗后方出现白金圣光。
- 羽毛 / 光尘从下向上逆流。
- 一道白金“命运流星”穿过教堂穹顶。
- 塔罗牌背浮现十字与圆环纹章。
- 稀有度越高，圣光越强，SSR 出现短暂全白闪屏和双重钟声。

### 2.2 地狱逆位演出

- 烛火瞬间熄灭。
- 教堂钟声低沉变调。
- 地面出现暗红裂纹和黑雾。
- 一道红黑“命运流星”逆向坠落。
- 塔罗牌背出现倒置纹章 / 裂痕 / 红色封印。
- SSR 先完全黑屏，再出现一瞬红色眼光或角色剪影，随后爆出牌面。

### 2.3 稀有度

首版固定：

- R：70%
- SR：25%
- SSR：5%

视觉不使用“原神星星”样式，改成：

- R：银白光
- SR：紫金光
- SSR：虹金 / 黑金爆光（天堂与地狱分别做不同版本）

SSR 必须有更长的角色登场演出与专属音效节点。

## 3. 三位修女老板娘的专属演出

### 3.1 龙卷｜XVI · THE TEMPEST｜风暴

核心气质：嘴毒、没耐心、傲娇式管教、暴力训诫感。

动画：

- 塔罗牌先在远处漂浮。
- 绿色念动力粒子包住全部牌。
- 五张牌被“硬扯”到玩家面前并高速急停。
- 玩家点中一张后，其他四张被念动力直接甩飞。
- 龙卷立绘从侧面切入，伴随绿色碎片与风压。

天堂关键词：庇护、赦免、护短、霸道宠爱。

地狱关键词：罚站、训话、打屁股梗、拎走、社死称号。

### 3.2 山城恋｜IV · THE DOMINION｜支配

核心气质：从容、高高在上、绝对命令、服从感。

动画：

- 黑金王座 / 教堂高台先出现。
- 山城恋坐定后，五张牌自动悬浮在她面前。
- 牌移动速度很慢，强调“你没有逃离审判的必要”。
- 玩家点牌后，山城恋抬手，牌自行翻转。
- SSR 时出现短暂王冠纹章与“绝对命令”文字特效。

天堂关键词：认可、嘉奖、特权、修女长宠爱。

地狱关键词：命令、服从、羞耻称号、指定行为、乖狗狗梗。

### 3.3 李柚巴｜X · THE WAGER｜赌局

核心气质：坏笑、赌徒、看热闹不嫌事大、幸运 / 翻倍 / 归零。

动画：

- 五张塔罗牌像扑克一样被抛到桌面。
- 李柚巴从画面边缘探身，做“要不要赌一把”的表情。
- 玩家点牌后，牌先旋转一周再翻面。
- 她的卡牌可以额外触发 `Double or Nothing`。
- SSR 时牌面先变成老虎机式滚动，再锁定最终结果。

天堂关键词：鸿运、重抽、翻倍奖励、解除旧刑罚。

地狱关键词：赌债、翻倍刑罚、再赌一次、输光运气。

## 4. 塔罗选择规则

玩家看到的五张牌在选择前不得暴露内容。

为了防止“点不同位置实际固定某张卡”的伪随机感，规则固定为：

- 进入抽卡演出时先由后端确定角色、牌池与最终候选集合。
- 五张牌中至少 1 张为本次已锁定的最终结果；点击后由服务端完成最终确认。
- 客户端只负责动画，不得自行决定结果。
- 所有随机结果必须可在后端日志中以匿名 session id 复核。

李柚巴的 `Double or Nothing` 属于二阶段随机事件，必须由后端二次掷骰。

## 5. 昵称前缀刑罚引擎

这是第一版最重要的“实体刑罚”。

### 5.1 基本规则

执行前必须保存：

- Discord user id
- guild id
- 原始 server nickname
- 刑罚牌 id
- 生效时间
- 到期时间
- 当前执行状态

显示昵称规则：

`刑罚前缀 + 原昵称`

示例：

- `zero` → `被龙卷打屁股的zero`
- `zero` → `正在服从山城恋命令的zero`
- `zero` → `输给李柚巴的zero`

不得通过“字符串删除前缀”恢复昵称；必须恢复执行前保存的原始昵称。

### 5.2 昵称长度

不得假设平台长度恒定；实现时读取 / 按 Discord 当前限制安全裁剪。

优先级：

1. 保留刑罚前缀语义完整。
2. 尽量保留原昵称。
3. 超长时对原昵称做省略号裁剪。

### 5.3 同时存在多个刑罚

为了避免昵称爆炸，首版固定：

- 服务器可同时记录多个“刑罚状态”。
- **昵称只显示一个最高优先级的可见刑罚。**
- 其他刑罚保留在 Activity 的“罪孽簿”中，不继续叠加到昵称。
- 新刑罚优先级更高时，暂时覆盖旧前缀；到期后恢复仍有效的下一条刑罚。

优先级：`SSR > SR > R`；同稀有度按最新生效时间优先。

### 5.4 天堂清除

部分天堂牌可执行：

- 清除当前可见昵称刑罚。
- 清除一个随机地狱状态。
- 清除全部普通地狱状态（SSR 天堂）。

但不得删除管理员手工设置的普通 Discord 昵称状态；恢复以系统保存快照为准。

## 7. 临时身份组引擎

身份组是第二种“实体判决”。

### 7.1 系统创建的专属身份组

首版建议静静自动创建或校验以下角色：

通用：

- `☁️ 受祝福的灵魂`
- `🔥 正在受罚`
- `✨ 神迹眷顾`
- `🕯️ 忏悔中`

龙卷：

- `🌪️ 风暴训诫中`
- `🌪️ 龙卷罩着的人`

山城恋：

- `👑 修女长的宠儿`
- `🐕 修女长认证·乖狗狗`

李柚巴：

- `🎲 赌债未清`
- `🎰 JACKPOT 幸运儿`

### 7.2 角色规则

- 每个身份组必须记录由哪张牌添加。
- 到期只移除系统自己添加的角色，不碰用户原有角色。
- 如果用户此前已经拥有同名角色，不得错误删除；需通过 role id 管理。
- 同一类别只保留最高优先级状态。
- SSR 可覆盖 R / SR 视觉角色，但后台状态仍保留用于恢复链。

### 7.3 持续时间

首版固定四档：

- 30 分钟：轻度玩笑
- 6 小时：标准刑罚 / 奖励
- 24 小时：SR
- 直到下一次相反裁决：部分 SSR

卡牌 manifest 必须明确写 `duration_mode`，禁止散落在前端代码里。

## 8. 天堂与地狱的“实体效果语法”

每张卡允许包含 0～3 个 effect：

- `nickname_prefix`
- `add_role`
- `remove_role`
- `cleanse_penalty`
- `double_penalty`
- `reroll`
- `grant_immunity`
- `add_title`

同一张牌可以组合，例如：

`龙卷 SR 逆位｜风暴训诫`

- 改昵称前缀：`被龙卷打屁股的`
- 添加角色：`🌪️ 风暴训诫中`
- 持续 6 小时

`山城恋 SSR 正位｜绝对嘉奖`

- 添加角色：`👑 修女长的宠儿`
- 清除当前 1 个地狱昵称刑罚
- 持续 24 小时

`李柚巴 SSR 逆位｜梭哈`

- 当前刑罚先锁定
- 弹出 `再赌一把？`
- 50%：当前刑罚全部取消
- 50%：当前刑罚时长翻倍，并追加 `🎲 赌债未清`

## 9. 失败与降级

Discord 权限不足时不得让玩家看到“抽到了但什么都没发生”。

若昵称修改失败：

- 保留塔罗结算。
- 显示：`实体刑罚执行失败，已转为忏悔室内部称号。`
- 将昵称前缀改为 Activity 内部 badge。

若身份组添加失败：

- 同样降级为 Activity 内 badge。

若 Bot 身份组层级低于目标用户：

- 明确记录 `ROLE_HIERARCHY_BLOCKED`。
- 不允许无限重试。

---

## 10. 恢复与持久化

昵称与角色恢复属于 P0。

必须支持：

- Bot 重启后继续恢复未到期刑罚。
- Activity 关闭不影响计时。
- 用户离开服务器后重新加入时，不应错误重放过期刑罚。
- 管理员人工改昵称后，自动恢复不得覆盖管理员后续手动修改；需做“当前昵称是否仍等于系统最近写入值”的保护判断。
- 所有恢复操作都要幂等。

## 11. 卡牌 manifest 必须包含的字段

每张牌至少：

- `id`
- `owner`：tatsumaki / ren / yuzuha
- `orientation`：upright / reversed
- `rarity`：R / SR / SSR
- `title_cn`
- `subtitle`
- `judgement_text`
- `image_url`
- `effects[]`
- `duration_mode`
- `weight`
- `enabled`
- `adult_mode_required`

所有运行时卡面由 GitHub 云端素材目录加载。

角色目录当前固定：

- `public/assets/tarot/characters/龙卷/`
- `public/assets/tarot/characters/山城恋/`
- `public/assets/tarot/characters/李柚巴/`

## 12. 成人 / 禁忌模式边界

禁忌模式必须是明确 opt-in 的 18+ 开关。

公开昵称与公开身份组只允许搞怪、暧昧、羞耻、服从感措辞，不使用露骨色情描述。

更成人化的判词只能出现在忏悔者自己的 Activity 私密结算界面中。

## 13. 首版验收标准

P0：

- 天堂 / 地狱裁决能稳定进入不同动画分支。
- 三位老板娘的抽卡演出视觉可一眼区分。
- 五张塔罗牌可以真实点击并只结算一次。
- R / SR / SSR 稀有度预告正确。
- 至少一张龙卷牌能真实改昵称并自动恢复。
- 至少一张山城恋牌能真实添加 / 回收临时身份组。
- 至少一张李柚巴牌能真实执行 Double or Nothing。
- Bot 重启后未到期刑罚仍可正确恢复。
- 权限不足时降级而不是报死。

P1：

- 60 张完整判决牌。
- 角色专属音效与 SSR 特效。
- 罪孽簿 / 恩宠簿。
- 天堂净化与地狱叠层。

## 14. 本轮冻结结论

忏悔室真正的核心不是“聊天”，而是：

**修女裁决 → 忏悔者亲手抽牌 → 三位老板娘之一降临 → 塔罗翻面 → Discord 服务器真实发生变化。**

后续实现不得把昵称前缀和身份组做成纯 UI 假效果。
