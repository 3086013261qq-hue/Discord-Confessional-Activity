## 1. 龙卷牌组总规则

- 天堂 = 正位；地狱 = 逆位。
- 龙卷牌组 UI 主色：黑 / 白 / 翡翠绿 / 少量金。
- 召唤动画：绿色念动力裂光 → 塔罗牌被“拽”到屏幕中央 → 牌角悬浮 → 翻面。
- 任何昵称效果都必须保存 `original_nickname`，到期恢复原值。
- 昵称不得无限叠加；同一时间只允许一个主动昵称判决效果生效。
- 若昵称过长，必须优先保留刑罚前缀，再安全截断原昵称，不能让 API 失败。
- 身份组全部为 Bot 管理的临时装饰组，不修改频道权限，不造成禁言、踢出、封禁等管理处分。
- 天堂牌可以解除或覆盖地狱牌；SSR 天堂牌优先级最高。
- 逆位牌最高持续时间默认不超过 24h；除非后续施工单明确另行批准。

建议权重：
- R：60%
- SR：30%
- SSR：10%

# 2. 天堂正位｜10张

## H-TAT-01｜R｜《风暴庇护》

**判词**：
> “别误会。我只是懒得看你继续倒霉。”

**实体效果**：
- 添加临时身份组：`🌪️ 被龙卷罩着`
- 持续：6h

**Activity 效果**：
- 结算页出现绿色护盾环。

**动画钩子**：
- 牌面翻开后，念动力碎片在玩家头像四周组成护盾。

> “只能算勉强。别露出那副得意的脸。”

**实体效果**：
- 昵称临时变更：`被龙卷勉强认可的{原昵称}`
- 持续：3h

**恢复**：
- 到期恢复原昵称。

## H-TAT-03｜R｜《小小赦免》

**判词**：
> “这次算了。下一次可没这么便宜。”

**判词**：

- 新牌必须接受，不能连续重抽。

---

## H-TAT-10｜SSR｜《暴风眼的庇护》

**判词**：
> “站到我后面。剩下的不用你管。”

**SSR 演出**：
- 全屏先静止 0.8s。
- 所有绿色碎片倒流。
- 龙卷剪影出现，抬手后形成巨大翡翠色圆形风眼。
- 双重钟声 + 低频念动力轰鸣。

**实体效果**：
- 立即清除当前所有由本 Bot 添加的昵称刑罚。
- 立即移除当前所有由本 Bot 添加的临时刑罚身份组。
- 添加身份组：`🌪️ 暴风眼庇护`
- 持续：24h

**附加状态**：
- 24h 内下一次地狱 R / SR 实体刑罚自动降级为“只显示判词，不执行服务器修改”。
- SSR 地狱牌不受保护。

## P-TAT-10｜SSR｜《暴风眼》

**判词**：
> “很好。你成功让我认真起来了。”

**SSR 演出**：
- 全屏黑 0.6s。
- 一只绿色眼光在黑暗中亮起。
- 教堂彩窗被念动力震碎为悬浮碎片。
- 五张塔罗牌同时被掀飞，只剩这一张逆位牌停在中央。
- 低频轰鸣 + 单次重钟。

**实体效果**：
- 昵称：`被暴风眼盯上的{原昵称}`
- 身份组：`🌪️ 暴风眼重点观察`
- 持续：12h

**追加效果**：
- 从龙卷 R 级地狱牌中再随机抽取 1 张“副刑罚”。
- 副刑罚若为昵称类，则不再改昵称，只执行其 Activity 文案或身份组部分，避免昵称叠加。
- 副刑罚持续时间固定缩短为 2h。

**兜底**：
- 若所有副刑罚都因权限问题无法执行，则追加 Activity 内称号：`龙卷今天真的很生气`。

# 4. 昵称模板规则

统一模板：

```txt
{判决前缀}{original_nickname}
```

第一版龙卷正式前缀：

```txt
被龙卷勉强认可的
被龙卷偏爱的
被龙卷打屁股的
被龙卷拎起来训话的
龙卷认证的笨蛋
正在接受龙卷训诫的
正在被龙卷公开训话的
被暴风眼盯上的
```

要求：
- 必须保留原昵称主体。
- 超出 Discord API 允许长度时，程序自动截断原昵称尾部，并加省略符。
- 不允许截断判决前缀本身。
- 用户在刑罚期间手动改昵称时，恢复逻辑不得粗暴覆盖用户新昵称；应记录 `punishment_applied_nickname`，仅在当前昵称仍等于该刑罚昵称时自动恢复，否则标记 `manual_nickname_changed=true`，停止自动覆盖，并在后台保留恢复提示。

# 5. 龙卷专属身份组

第一版正式身份组：

```txt
🌪️ 被龙卷罩着
💚 龙卷今天没骂我
🌪️ 风暴保护对象
💚 风暴偏爱
🌪️ 暴风眼庇护
🌪️ 风暴训诫中
🤐 不许顶嘴
⚠️ 被龙卷警告三次
🌪️ 欠龙卷一次反省
💚 今日反面教材
🌪️ 暴风眼重点观察
```

规则：
- 全部由 Bot 创建 / 管理。
- 只做视觉称号，不改频道访问、消息发送、语音权限、管理权限。
- 每个角色身份组应有独立命名空间 / 数据表记录，避免与服务器已有同名角色混淆。
- 到期只删除“Bot 本次添加到该用户”的角色关系，不删除服务器中的角色定义本身。

# 7. QA 必测

静静施工后至少验证：

1. 天堂不会抽到任何逆位牌。
2. 地狱不会抽到任何正位牌。
3. 20 张龙卷牌都能进入抽卡池。
4. 昵称变更成功后能按时恢复。
5. 用户刑罚期间手动改昵称不会被 Bot 粗暴覆盖。
6. 多个昵称刑罚不会叠成连续前缀。
7. 身份组到期正确回收。
8. 不修改任何真实频道权限。
9. Bot 身份组层级不足时，必须明确降级，不得伪装执行成功。
10. SSR《暴风眼》副刑罚不会触发第二次昵称覆盖。
11. SSR《暴风眼的庇护》能正确清理 Bot 管理的旧刑罚。
12. Android Discord Activity 内抽卡动画可正常完成，不因低性能设备卡死。
13. `prefers-reduced-motion` / 低性能模式下可缩短粒子和震屏，但不能跳过核心翻牌结果。

## 8. 冻结结论

龙卷第一版正式牌组固定为：

- 天堂正位：10 张
- 地狱逆位：10 张
- 合计：20 张

第一版核心体验必须让玩家明确感受到：

> **“龙卷不是在给你发一条随机文本，而是真的通过塔罗牌把她的审判执行到了 Discord 服务器里。”**

后续新增龙卷牌只能追加，不得无理由替换本文件已冻结的 20 张首发牌。
