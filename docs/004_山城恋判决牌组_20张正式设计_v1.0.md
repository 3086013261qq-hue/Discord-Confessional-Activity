## 1. 山城恋牌组总规则

- 天堂 = 正位；地狱 = 逆位。
- UI 主色：黑 / 象牙白 / 深紫 / 暗红 / 少量金。
- 召唤动画：烛火排成仪式轴线 → 王座轮廓出现 → 五张塔罗在空中整齐列阵 → 山城恋抬眼 → 目标牌缓慢翻面。
- 她的抽卡节奏必须明显慢于龙卷，强调“你正在等待她宣判”。
- 昵称与身份组均属于游戏化社交效果，不赋予真实管理权，不禁言、不踢出、不封禁。
- 昵称效果必须保存原昵称，并遵守 002 的安全恢复规则：若用户期间手动改名，则到期不得粗暴覆盖新昵称。
- 山城恋的牌强调“认证 / 命令 / 服从 / 嘉奖”，避免做成与龙卷相同的暴力训诫。
- 最高持续时间默认不超过 24h。

建议权重：
- R：60%
- SR：30%
- SSR：10%

## P-REN-10｜SSR｜《伏首》

**判词**：
> “既然选择接受审判，就把最后一步做完。”

**SSR 演出**：
- 屏幕完全暗下。
- 只保留王座与山城恋眼睛的微光。
- 五张塔罗整齐竖立，随后同时倒扣。
- 中央逆位牌缓慢下降到屏幕正中。
- 山城恋抬手，牌面无声翻转。
- 翻面后先静默 0.8s，再响一次沉钟。

**Activity 仪式**：
- 显示两个按钮：`接受审判` / `请求宽恕`

### 选择 A：接受审判
- 昵称：`正在服从山城恋命令的{原昵称}`
- 身份组：`👑 伏首`
- 持续：12h
- 额外显示金色印章动画：`ORDER ACCEPTED`

### 选择 B：请求宽恕
- 山城恋发送一张修女表情贴纸。
- 再弹一次确认：`真的要求饶吗？`
- 若确认：本牌降级为 P-REN-07《乖狗狗认证》，持续时间改为 8h。
- 若取消：返回“接受审判”。

**限制**：
- 不允许无限循环点击求饶。
- 请求宽恕最多一次。

# 4. 山城恋专属抽卡演出差异

必须与龙卷明显不同：

### 龙卷
- 快
- 暴力
- 念动力拉扯
- 裂光 / 碎片 / 冲击

### 山城恋
- 慢
- 安静
- 仪式感
- 王座 / 烛火 / 对称构图 / 紫金纹章

山城恋牌面抽取时：
1. 五张牌必须排列得非常整齐。
2. 玩家点击其中一张后，不立即翻面。
3. 山城恋先抬眼看向画面。
4. 被选中的牌移动到王座前。
5. 牌背出现紫金印章。
6. 稀有度先显现。
7. 最后翻面。

SSR 时，禁止使用与龙卷相同的爆炸式光效；应以“静默、压迫、缓慢”制造稀有感。

# 6. 昵称安全规则

山城恋昵称刑罚示例：
- `山城恋认证的乖孩子zero`
- `被山城恋亲自嘉奖的zero`
- `正在向山城恋反省的zero`
- `山城恋认证的笨蛋信徒zero`
- `山城恋认证的乖狗狗zero`
- `正在御前反省的zero`
- `正在服从山城恋命令的zero`

实现要求：
- 保存原昵称与 applied nickname。
- 到期恢复前先检查当前昵称是否仍等于 applied nickname。
- 若用户期间自行改名，则只结束刑罚状态，不覆盖用户新昵称。
- 超长时优先保留判决前缀，安全截断原昵称。
- 不得把多个前缀无限叠加。

# 7. 表情包联动

山城恋牌组必须调用已规划的修女表情贴纸系统：

- P-REN-03《口头命令》：确认后随机发送 1 张“满意 / 盯着你 / 记录”类表情。
- P-REN-06《绝对命令》：完成选项后发送 1 张“盖章 / 微笑”类表情。
- P-REN-09《御前反省》：三次点击分别发送不同表情。
- P-REN-10《伏首》：若请求宽恕，发送 1 张“坏笑 / 居高临下”类表情。

不得把表情包只当静态装饰；它属于判决流程反馈。

# 8. QA

必须验证：

1. 10 天堂 + 10 地狱共 20 张均可被抽中。
2. 权重近似符合 R 60 / SR 30 / SSR 10。
3. 天堂与地狱牌池完全隔离。
4. 山城恋 SSR 演出不复用龙卷爆炸式动画。
5. 所有身份组均无管理权限。
6. 昵称恢复逻辑不会覆盖玩家后续自行修改的新昵称。
7. P-REN-06 三选一按钮在 Android 端可正常点击，触控区域 >= 44px。
8. P-REN-10 请求宽恕最多触发一次，不可无限循环。
9. 所有表情包发送不泄露匿名玩家的真实 Discord 身份。
10. 权限不足时实体效果必须降级并提示，不允许无声失败。

## 9. 冻结结论

山城恋首发牌组正式冻结为：

**10 张天堂正位 + 10 张地狱逆位。**

她的角色体验必须始终保持：

**“不是大喊大叫，而是她一句话，你就知道该照做。”**

不得在施工阶段把她改成龙卷式暴力训诫，也不得将其做成真实惩戒型 Discord 管理工具。
